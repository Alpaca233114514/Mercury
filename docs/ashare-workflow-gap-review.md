## 风控缺口的独立合成检查

审计子代理使用临时CNY账户和合成T+0 ETF数据，没有修改仓库或用户实验账本，也没有联网或真实成交：

- 初始100000假钱，单笔名义金额90000可成交，单标的仓位约90.04%；空决策依据可接受。
- 同日8笔成交累计成交额720000，相当于初始资金7.2倍。
- 累计收益约-8.55%后，新买单仍被接受。

这说明当前程序执行已实现的账本/交易规则，但没有参考流程要求的独立投资风险限额；不是账本算错，也不是实际策略收益证据。

## 建议的A股补齐顺序

1. **冻结观察与决策协议**：按A股交易日历生成Observation清单，绑定行情、公告/财报发布时间、证券状态、规则版本与hash；TradeIntent严格引用该观察和策略版本。
2. **硬风控**：可配置的CNY单笔金额、单标的仓位、日换手、日亏损上限，纳入已有挂单与费用；缺估值或资料时拒绝。将模型可写区域与风控/执行写权限分开。
3. **自主循环**：研究→策略→意图→风控→本地撮合→复盘状态机，保留失败、重试、幂等、恢复及每轮产物。仍只使用本地假钱。
4. **策略与评测运行器**：受限DSL、历史回放、同观察同CNY资金的多模型episode；按股票池选取A股指数或买入持有基准，明确复权、公司行为与幸存者偏差。
5. **更逼真的模拟**：有数据支持后增加价差、延迟、部分成交等，分开报告合成验证和真实前向表现。

其中策略阈值、股票池、基准及交易频率需成为显式实验配置；参考对话里的美股/SP500或示例限额不是A股项目的默认配置。

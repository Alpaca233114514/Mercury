# 数据与模型评测约定

当前交付包括账本、行情采集/缓存、冻结观察、受限策略、硬风控、有限循环与共享观察评测运行器，见[流程接口](workflow-cli.md)。尚未下载真实历史全集，也没有完成模型收益实验。

## 三种实验分开记录

| 实验 | 可以说明什么 | 不能声称什么 |
| --- | --- | --- |
| Historical price-only | 在仅价格观察下的历史策略行为 | 匿名化完全消除了预训练记忆 |
| Historical realistic | 模型世界知识与所给历史材料的综合行为 | 严格无污染的预测能力 |
| Live forward | 决策时刻以后的真实新行情下的模拟表现 | 假钱撮合等同真实交易所成交 |

本仓库 `demo` 是合成功能检查，`replay` 是基础历史撮合模式，`live` 是前向假钱模式；未内置 price-only 匿名化与隔离运行器。

## 采集子代理

采集和审计子代理默认 GPT-6 Sol High。任务模板：

> A股只读使用已审查的 ashare-mcp，全球对照使用 Financial Datasets MCP，按指定标的和日期范围采集；调用参数、原始响应、供应商时间、received_at 和工具名称保存至新文件。不编造数据，不触及券商接口。不读或打印 API key。使用本地 ashare-analyze / analyze-history 计算，不凭模型心算。报告行数、起止日期、分页状态、缺失字段、失败和来源；数据不全时不能声称采集完成。

历史采集应分标的、分日期窗口，保留每个批次的失败记录和 SHA-256。当前一次工具调用最多得到服务返回的一页，实际权限和配额以用户账户为准。旧 stdio 数组无法证明没有下一页，当前 hosted 返回也要实际验证。

## 样本与基准

参考对话的 300–1000 个标的、5–10 年日线仅作为数据规划示例，不是本项目已达到的规模或统计充分性证明。每次实验记录：

- 模型/版本、策略/提示词版本、决策时点、账户路径、初始资金、费用/滑点、行情证据、股票池与时间窗。
- 覆盖标的数、独立日期数、缺口、停牌/退市与公司行为处理方式、历史复权方式和财报真实可用时间。
- 净收益、费用、滑点成本、已实现/未实现盈亏、回撤观察点与基准。`report` 提供零息现金基准；`compare` 可接收有来源和覆盖约束的对齐买入持有/指数价格序列，但不会自动取得真实基准或把指数当股票下单。
- 每个模型独立账户，同一可见行情集合和决策频率；训练/选择期与最终评测期分开，不能反复挑好看的窗口。

`report` 不根据稀疏、不等间隔快照输出年化 Sharpe，也不把盈利卖出笔数比例称为完整往返交易胜率。新增完整仓位从零到零交易分组及未年化名义换手率。`compare` 仅在明确完整日采样、交易日历和至少20个收益样本时计算Sharpe；日内regular尚无可信时段网格，明确返回null。快照应按固定计划保存；少记快照可能漏掉真实最大回撤。

## 时序与隔离

FDM daily bar 在下一天 UTC 零点视为已知；A股日线/分钟使用接入层记录的收盘/可用时刻约定。这些不是实际供应商首次发布时间证明。`advance` 只前进，冻结观察按行情和可用时刻裁切，历史订单必须在之后的合格行情成交；不能把日线收盘价搬到连续竞价时段回填成交。

加载历史时整个数据集保存在本地，拥有任意 shell/文件访问的 agent 仍可看到未来数据。因此不能声称当前 CLI 构成盲测隔离。严格评测还需要由独立运行器隐藏数据文件和密钥，只暴露按时点裁切的观察工具。

历史数据的供应商修订、后复权、财报修订和模型自身记忆均可能造成泄漏。未解决这些问题时，历史结果仅为诊断。

## 独立审计

内建 `audit` 核对账本，不替代另一名子代理审查。审计任务至少包含：资金守恒、平均成本与净盈亏、费用/滑点、订单预留、并发幂等、成交与报价的时间关系、原始响应绑定、缺失估值、数据规模和宣传结论。保留初审发现与修复后复核证据，见 `AGENTS.md`。
